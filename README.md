# SQL Scripts - Study Guide

Welcome to the structured SQL learning path! This repository contains scripts organized in a progressive order, moving from basic database concepts to advanced querying and performance optimization.

## 📚 Recommended Order of Study

| Order | Topic / File Name | Description |
| :---: | :--- | :--- |
| **01** | [Before Functions] | Basics of SQL queries, filtering, sorting, and data manipulation. |
| **02** | [Functions] | Built-in string, numeric, and date functions. |
| **03** | [Primary & Foreign Keys] | Establishing table relationships, constraints, and data integrity. |
| **04** | [Unions & Self Joins]| Combining result sets and joining a table to itself. |
| **05** | [Views & Indexes] | Creating virtual tables and optimizing query performance. |
| **06** | [Subqueries] | Writing nested queries for complex data filtering. |
| **07** | [Group Summaries] | Aggregating data using `GROUP BY`, `HAVING`, and aggregate functions. |
| **08** | [Procedures & Triggers] | Automating database logic with stored procedures and triggers. |
| **09** | [Cases in SQL] | Conditional logic using `CASE` statements. |
| **10** | [Common Table Expressions (CTE)]| Writing cleaner, modular queries using temporary result sets. |
| **11** | [Recursive CTE] | Handling hierarchical or tree-structured data. |
| **12** | [Window Functions] | Performing calculations across rows related to the current row. |
| **13** | [Window Functions (Advanced/All)]| Comprehensive deep dive into advanced window frames and analytics. |

---
*Tip: Follow the numerical sequence sequentially to build a solid foundation from basic queries to expert-level SQL concepts.*
