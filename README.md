# SQL Scripts - Study Guide

Welcome to the structured SQL learning path! This repository contains scripts organized in a progressive order, moving from basic database concepts to advanced querying and performance optimization.

## 📚 Recommended Order of Study

| Order | Topic / File Name | Description |
| :---: | :--- | :--- |
| **01** | Basics of SQL queries, filtering, sorting, and data manipulation. |
| **02** | Built-in string, numeric, and date functions. |
| **03** | Establishing table relationships, constraints, and data integrity. |
| **04** | Combining result sets and joining a table to itself. |
| **05** | Creating virtual tables and optimizing query performance. |
| **06** | Writing nested queries for complex data filtering. |
| **07** | Aggregating data using `GROUP BY`, `HAVING`, and aggregate functions. |
| **08** | Automating database logic with stored procedures and triggers. |
| **09** | Conditional logic using `CASE` statements. |
| **10** | Writing cleaner, modular queries using temporary result sets. |
| **11** | Handling hierarchical or tree-structured data. |
| **12** | Performing calculations across rows related to the current row. |
| **13** | Comprehensive deep dive into advanced window frames and analytics. |

---
*Tip: Follow the numerical sequence sequentially to build a solid foundation from basic queries to expert-level SQL concepts.*
